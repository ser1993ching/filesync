# FileSync

Windows 上的**低内存双目录双向实时同步工具**，支持本地盘、本地盘与 NAS/SMB 共享目录之间的同步。

- **双向同步**：本地 → NAS、NAS → 本地均为核心能力；也支持本地盘 ↔ 本地盘。
- **低内存优先**：流式扫描、有界队列、固定复制缓冲、轻量自绘 UI。
- **技术栈**：.NET 8（按产品要求固定）、无 SQLite、journal + snapshot。
- **安全可靠**：三方基线、KeepBoth 冲突保留、首次同步只读预览、删除回收区与熔断。
- **NAS 免安装**：通过 SMB/UNC 访问，不要求 NAS 安装 Agent。

## 当前关键决策

1. 同步任务的 A/B 两端是对等端点，默认双向；NAS 既能接收本地变化，也能作为变化源向本地盘同步。
2. 低内存是 P0 产品要求，不允许以重量级 UI 框架或全量内存清单换取便利。
3. 运行时固定 .NET 8；不擅自升级运行时。
4. 默认无 SQLite，使用纯托管 journal + snapshot。
5. 首轮只读清点后由用户确认；冲突默认 KeepBoth；删除进入回收区并受熔断保护。
6. NAS/SMB 端通过 FSW 提示 + 周期对账发现变化；远端不可访问时绝不把不可访问当成删除。

## 设计原则

- 正确性优先于事件速度：监控事件只是提示，最终通过文件系统状态与三方基线判断。
- 安全优先于自动覆盖：有歧义时保留双方内容或等待用户决策。
- 内存有界优先于峰值吞吐：限制缓存、队列、并发与复制缓冲。
