# FileSync

Windows 上的**低内存双目录双向同步工具**，支持本地盘、本地盘与 NAS/SMB 共享目录之间的同步。

- **双向同步**：本地 → NAS、NAS → 本地均为核心能力。
- **低内存优先**：流式扫描、有界队列、固定复制缓冲、磁盘化索引、轻量自绘 UI。
- **技术约束**：按产品决策使用 .NET 8、纯托管 Journal + Snapshot、无 SQLite。
- **安全可靠**：三方基线、KeepBoth、首次同步只读预览、删除回收、熔断和崩溃恢复。
- **NAS 免安装**：通过 SMB/UNC 访问，不要求 NAS 安装 Agent。

## 已确认的产品约束

- A/B 是对等端点，默认 TwoWay；NAS → 本地和本地 → NAS 都是 P0。
- NAS 通过 SMB/UNC 访问，不要求 NAS 安装 Agent。
- 低内存是核心产品要求；所有队列、缓存、并发和传输缓冲必须有上限。
- 按已确认决策使用 .NET 8；不在文档升级过程中擅自改为其他目标框架。
- 默认无 SQLite，使用纯托管 Journal + Snapshot；其一致性、压实和恢复由 FileSync 自己负责。
- 首轮只读清点；默认 KeepBoth；删除先进入回收区并受熔断保护。
- FSW、USN 和 SMB Change Notification 都是变化提示；最终一致性依赖完整性可验证的对账。

## 重要风险说明

截至 2026-11-23，.NET 8 已于 2026-11-10 结束 Microsoft 支持。项目仍按已确认约束保留 .NET 8，但发布前必须确认接受不再获得后续安全更新的风险，并保留未来升级评估路径。详见 v3 低内存与存储架构文档。

**实现规则：** 旧文档与 v3 实现规范冲突时，以 v3 技术架构总览及其五份专题规范为准；产品行为以 PRD 为准。任何实现变更必须同步更新测试门禁。
