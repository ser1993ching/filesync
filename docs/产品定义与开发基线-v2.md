# FileSync 产品定义与开发基线

> 产品基线版本：v2.0（产品决策仍有效）
> 技术架构版本：v3.0（实现规范）
> 本文件只保留产品范围和已确认约束；同步算法、事务、存储、端点能力和测试细节以 v3 专题文档为准。

## 1. 产品定位

FileSync 是面向 Windows 的低资源双目录双向同步工具，连接本地文件夹与本地/NAS 文件夹。用户选择 A、B 两端，系统持续发现变化、判断差异、同步内容、保留冲突版本，并在断线或异常时保护数据。

核心价值：
1. 本地与 NAS 双向同步；
2. 低内存、低干扰；
3. 冲突保留、删除保护和崩溃恢复；
4. 首次同步预览与可理解的任务管理；
5. NAS 无需安装 Agent，通过 SMB/UNC 访问。

## 2. 支持范围

| 场景 | 版本范围 |
|---|---|
| 本地盘 A ↔ 本地盘 B | P0 |
| 本地盘 ↔ NAS/SMB | P0，两个方向同等重要 |
| 外接盘 ↔ 本地盘 | P1，设备离线时暂停 |
| NAS ↔ NAS | 后续评估，不作为首个版本验收前提 |
| 多台电脑同时运行同一任务 | 仅在可靠 NAS 租约验证通过后开放；否则明确限制单客户端 |

NAS → 本地是双向同步的必要能力，不是单向下载功能。

## 3. 已确认的技术约束

- Windows 10/11 x64。
- 按用户已确认决策使用 .NET 8，不在本次文档升级中擅自更改。
- 默认不使用 SQLite，状态采用纯托管 Journal + Snapshot。
- UI 独立进程，Win32 + GDI 自绘。
- 本地 NTFS 可使用 USN 增量加速；NAS/SMB 使用事件提示和周期对账。
- A/B 对等，默认 TwoWay。
- 低内存是 P0 产品约束，所有缓存、队列、并发、传输缓冲必须有界。
- 默认 KeepBoth；删除默认进入回收区，并有数量/比例熔断。
- NAS 不可达、认证失败、权限不足、枚举不完整均不能视为远端删除。

## 4. 用户可见功能范围

### P0
- 创建/编辑/暂停/恢复/删除同步任务；
- 选择本地路径、UNC 路径，检查权限、重叠路径和端点状态；
- 首次同步只读扫描、差异预览、策略选择、二次确认；
- 双向新增、修改、重命名、删除和目录变更；
- 冲突中心，默认 KeepBoth；
- 删除/覆盖回收区与还原；
- 任务状态、扫描/同步阶段、进度、失败、冲突、上次完整对账时间；
- NAS 连接状态、凭据保护、断线重连；
- 日志、Dry-run、恢复和崩溃续作；
- 独立轻量 UI。

### P1
- 多任务管理和模板；
- 计划同步、限速、空闲时段、自动启动；
- 版本保留容量策略、批量冲突处理；
- 文件名兼容性预检、健康报告；
- USN 优化和扫描性能优化。

### P2
- 块级增量传输；
- 云端中继、跨设备拓扑、NAS Agent；
- 高级内容合并与复杂 ACL 映射。

## 5. 安全默认行为

- 首次同步未确认前不得改动用户文件。
- 冲突默认保留双方版本；不能确认内容相同则不得静默覆盖。
- 删除默认进入回收区；超过阈值暂停并要求确认。
- 端点状态不可信时不执行依赖缺失判断的删除。
- 覆盖前保留旧版本；旧版本无法安全保存时停止覆盖。
- 文件操作必须可恢复，基线只能指向已校验的提交结果。
- 任务 UI 必须显示“实时监控 + 最终一致性”，不承诺所有 NAS 秒级完成。

## 6. 低内存目标

初始目标保留为工程验收目标：引擎稳态 <40MB、普通同步峰值 <50MB、自绘 UI 4–7MB。测量必须同时报告 Managed Heap、Working Set、Private Bytes、Native Memory，并单独观察内核 Nonpaged Pool。目标未通过时必须提交真实报告，不得改变测量口径。
